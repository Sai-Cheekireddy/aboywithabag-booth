# ABOYWITHABAG — The Booth

A music artist site for ABOYWITHABAG built as a playable DJ booth: two CDJ-3000-style decks and a DJM-V10-style mixer.

- Load any release or mix on either deck, hit play, ride the faders, EQs, filters, Beat FX and crossfader.
- Decks play a live-synthesized preview groove (Web Audio) — **LISTEN** links out to the real release.
- Shows history, labels, and socials.

Static single-page site (`index.html`), no build step. Deployed on Vercel.

Keys: `Q` / `P` play deck 1 / 2 · `←` `→` crossfader · `S` sync deck 2.
